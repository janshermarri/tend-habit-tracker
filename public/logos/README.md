# tend — logo package (Sprout, 1b)

## Colours
- Sage `#5A7862` (light) · Sage `#8FAE97` (dark mode)
- Ink `#23251F` · Ink on dark `#E9EAE4`
- Background `#F3F1EC` · Dark background `#141614` · Paper `#FBFAF7`

## Type
Wordmark: **Newsreader** Regular (Google Fonts, OFL), lowercase, letter-spacing −2.5%.
The lockup SVGs use live text — outline "tend" in Figma/Illustrator before sending to print or third parties.

## Files
- `svg/tend-mark-*.svg` — symbol only (sage, sage for dark mode, ink, white)
- `svg/tend-lockup-light.svg`, `tend-lockup-dark-mode.svg` — symbol + wordmark
- `svg/tend-app-icon.svg` — rounded sage tile
- `svg/favicon.svg` — adapts to dark mode
- `png/icon-192.png`, `icon-512.png`, `icon-512-maskable.png` — PWA manifest icons
- `png/apple-touch-icon.png` (180) · `favicon-32.png` · `favicon-16.png`
- `png/tend-lockup-*.png` (1200×400) · `tend-social-1200x630.png` (Open Graph)

## Usage
- Clear space: at least the width of one leaf on every side.
- Minimum size: symbol 16px; lockup 80px wide.
- Keep the symbol sage or single-colour; don't recolour the leaves separately, add effects, or rotate.
- App icon: sage tile with paper-coloured symbol. Maskable version keeps the symbol inside the 80% safe zone.

The PWA icons are also copied into `code/public/`.
